\begin{notesummarybox}[RC filter recap]
  The time constant controls the cutoff and settling time.
  \[
    \begin{aligned}
      \tau &= RC \\
      f_c &= \frac{1}{2\pi\tau}
    \end{aligned}
  \]
  \begin{itemize}
    \item Slow changes pass through the filter.
    \item Rapid changes are attenuated.
  \end{itemize}
\end{notesummarybox}
