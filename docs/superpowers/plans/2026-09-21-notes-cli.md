# Notes CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for native execution, or superpowers:subagent-driven-development if the user chooses delegation. Steps use checkbox syntax for tracking.

**Goal:** Ship a Windows/Linux Go command that creates blank lecture sources using the approved formatting package and finalizes a lecture by retaining only its PDF.

**Architecture:** Embed the template and approved package in the executable. Keep argument parsing separate from filesystem operations. Cleanup holds a directory handle from inspection through confirmation and deletion, confines operations to that root, and removes the ownership marker last.

**Tech Stack:** Go 1.25 or newer, standard-library templates, JSON and `os.Root`; `golang.org/x/term` for reliable terminal detection; pdfLaTeX and Poppler for document verification. The development toolchain does not become a user runtime dependency.

**Spec:** `docs/superpowers/specs/2026-09-21-lecture-notes-design.md`

## Global Constraints

- The implementation language is Go.
- Prebuilt Windows and Linux executables require neither Go nor Python on the user's machine.
- This tool does not run a TeX compiler.
- Problem sets will never be typeset.
- Each lecture produces a separate PDF.
- Cleanup prompts by default and supports `--yes`.
- Preserve exactly the root `lecture.pdf`.
- No network access is required during normal use.
- New lectures contain no title page, date, prefilled section, or example content.
- Keep the approved modern-textbook styling and pronounced course/lecture header.
- Do not force-push or replace existing remote work.

## Review Focus

1. Spaces and underscores in valid paths: preserve paths and escape course underscores only in LaTeX (Task 1).
2. Windows reserved names and case-insensitive collisions: refuse unsafe names and existing targets without modifying them (Task 1).
3. Directory links, junctions, and linked PDFs: no deletion outside the opened lecture root and no linked final PDF (Task 2).
4. Missing, corrupt, or outdated ownership metadata: refuse before deleting any lecture content (Task 2).
5. Redirected input, cancellation, and interrupted deletion: preserve work on refusal and keep the marker for retry after partial failure (Tasks 2 and 3).

```go
func TestFinalizeKeepsOnlyUnchangedPDF(t *testing.T) {
    dir, err := New(t.TempDir(), "ECE342", "2")
    if err != nil { t.Fatal(err) }
    pdf := []byte("%PDF-1.7\nfixture for file-signature checks\n%%EOF\n")
    if err := os.WriteFile(filepath.Join(dir, "lecture.pdf"), pdf, 0644); err != nil { t.Fatal(err) }
    if err := os.Mkdir(filepath.Join(dir, "figures"), 0755); err != nil { t.Fatal(err) }
    if err := os.WriteFile(filepath.Join(dir, "figures", "sketch.txt"), []byte("figure"), 0644); err != nil { t.Fatal(err) }
    f, err := Inspect(dir)
    if err != nil { t.Fatal(err) }
    defer f.Close()
    if err := f.Apply(); err != nil { t.Fatal(err) }
    entries, err := os.ReadDir(dir)
    if err != nil || len(entries) != 1 || entries[0].Name() != "lecture.pdf" { t.Fatal(entries, err) }
    got, err := os.ReadFile(filepath.Join(dir, "lecture.pdf"))
    if err != nil || !bytes.Equal(got, pdf) { t.Fatal("PDF changed", err) }
    if _, err := Inspect(dir); err == nil { t.Fatal("accepted finalized folder") }
}
```
